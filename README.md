# ABU BOKKOR DEVS WORK

A responsive static website template for Minecraft server development services.

## Files
- `index.html` — homepage
- `login.html` — login page design
- `register.html` — registration page design
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and demo form handling
- `assets/` — optional concept image

## Deploy to Netlify
1. Upload these files to a GitHub repository (keep `index.html` in the repository root).
2. In Netlify, choose **Add new site → Import an existing project**.
3. Connect GitHub and select the repository.
4. Build command: leave blank. Publish directory: `.` (or leave default if it detects the root).
5. Deploy the site.

## Important
The login and registration pages are visual front-end demos only. They do not create accounts or authenticate users yet. Before collecting real user details, connect a secure authentication backend/provider and configure its redirect URLs and security rules. Replace the placeholder contact email and add your real Discord/social links before publishing.
